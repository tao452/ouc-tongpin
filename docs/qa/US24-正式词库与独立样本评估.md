[论文](https://arxiv.org/abs/2201.06025)，固定提交 `a0c55a945497ab58e94aef491180e1cf88ffb864`
的完整 test.csv。文件 SHA-256 为 `b06d31481f0d558b6dc8140408938abe8dba8083cd9976b4ba8f5c837fbe78ed`，
来源与 [Apache-2.0 许可证](data/external/COLD-LICENSE.txt)已留存。

共 5,323 行全部符合现有 1–2,000 字符非空输入约束，排除 0 行；包含的 3 行重复文本保留。
按上游标签，冒犯 2,107 条、非冒犯 3,216 条；标签和顺序不变，没有按是否命中词库挑选样本。
上游四类细标签按原数值分别统计，不擅自改为项目 HIGH 标签。
“独立”指样本采集和人工标签来自项目之外，不表示 M1/M3 已独立复核，也不表示该公开集是永久未见过的数据。
本版本评估后该测试集已被使用，后续若据其结果改模型，不能继续宣称同一数据为未触碰留出集。

原始 CSV 仅保存于被 Git 忽略的 `qa-private/`，不提交、不作为 CI artifact 上传，不回显原文或身份。
公开记录仅含汇总统计、输入/代码哈希、UTC 时间和版本信息。下载器验证固定字节数、哈希和许可证，
执行器拒绝输出覆盖语料、词库、配置或自身代码。

## 复现与自动化

仓库根目录、Python 3.11+ 环境中运行：

```powershell
python scripts/qa/fetch_cold_test.py --output qa-private/cold-test.csv
python services/algo/scripts/evaluate_external.py qa-private/cold-test.csv --output qa-private/cold-function.json
python services/algo/scripts/evaluate_external.py qa-private/cold-test.csv --base-url http://127.0.0.1:8000 --output qa-private/cold-http.json
```

HTTP 命令要求已经启动隔离的本地算法服务。诊断默认返回 0 仅表示完整执行，错误返回 2；
加 `--require-broad-thresholds` 后，广义召回低于 95% 或误报不低于 2% 返回 1。本次已实际验证该门禁返回 1。
CI、nightly 和临时全栈已接入固定数据评估，分别记录诊断指标和业务效果状态；
原有 300 条规则回归及单元测试仍作代码质量门禁。

本地完整 Python 测试 **222 项通过**，app 行与分支合计覆盖率 **98.55%**；Ruff、actionlint 和差异检查通过。
原始运行证据及哈希在 [`evidence/us24-20261115/`](evidence/us24-20261115/)，其中函数/HTTP 报告
均标记 `production_acceptance=false`、`m1_release_review=pending`。
