# US24 拼音语义分类开发训练与复测

首轮3个ChineseBERT checkpoint已完成实际训练及全部预测。在四组误报分别受控的条件下，PCR召回最高26.8%、ToxiCN开发验证最高29.49%，仍未达到95%目标。该模型继续离线开发，不产生S1风险等级。

## 数据与实现

使用[ChineseBERT作者模型](https://huggingface.co/ShannonAI/ChineseBERT-base/tree/aa8b6fa9c3427f77b0911b07ab35f2b1b8bf248b)与[原始MIT实现](https://github.com/ShannonAI/ChineseBert)。词语上下文拼音、字形与字符联合编码，单字只取一条上下文读音，8位拼音字符编码；最多510正文token、128重叠切窗，全部窗口保留，以最大窗口分数合成评论分数。模型权重和字体保持私有，原二进制仅通过`weights_only=True`读取。

ToxiCN12011条用固定SHA256分组得到9612条训练、2399条开发验证；PCR500、正常语境257条不参与梯度。固定3轮、AdamW学习率2e-5、batch8、累积4步、BF16、seed20261124，冻结字形像素查表，实际执行方案和分组在训练前固定。详细参数见[开发方案](US24-拼音语义分类开发方案.md)。

首轮输入在`d8a243e`的3.5语境实现下固定，3轮各预测3156条、总9468条。之后用3.6语境重新构造输入并加入102条新语境，3轮各预测3258条、总9774条；原3156条的ID、标签、原文哈希全部相同，转换后的文本变化0条。新增102条仍不参与训练。

第二组补充COLD官方train的2轮训练已经完成，后续拼音增强、固定组合和排名损失对照也已实测，结果见下表。全部开发评估和历史COLD结果保留。COLD dev尚未获取；开发门槛通过后再冻结唯一配置执行预留外部对照，M3仍需封存校园新样本。全部候选词、等级、变体及豁免的M1状态保持PENDING。

同一35293条训练及3258条评估的字符、拼音TF-IDF线性对照已经完成，已收敛、推理错误0。在0.5阈值，ToxiCN开发Recall70.82%、FPR26.20%，PCR Recall26.40%、FPR6.40%，正常语境257条FPR65.76%，新增90条正常语境FPR24.44%。在各组FPR<2%约束下，与字面规则组合的最佳阈值0.931：ToxiCN TP130/FP22/FN1162/TN1085，PCR TP54/FP0/FN196/TN250，Recall分别10.06%和21.60%；正常257条FP0，新增语境TP12/FP0/FN0/TN90，仍未达标。该结果说明简单词形与无调拼音特征不足以处理这些开发样本，完整分数和参数见[线性对照证据](evidence/us24-linear-phonetic-v1/manifest.json)。
