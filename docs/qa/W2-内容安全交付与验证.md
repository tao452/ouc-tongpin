## 真实容器验收

`deploy-test.yml` 构建 MySQL、Redis、Java、FastAPI 和管理端网关，验证健康与基础 HTTP 路由。
然后通过网关实际执行 300 条审核请求，并运行 `verify_treehole_moderation.py`：

1. 正常文本创建成功，返回 201；MySQL 与 Redis 各增加一条。
2. HIGH 返回 422，两者均不增加。
3. MEDIUM 和 LOW 按当前三级动作允许发布。
4. “去死海”等正常上下文允许发布。
5. 停止算法容器后，发布返回 503，MySQL/Redis 均不增加；finally 恢复容器。

容器验收以 PR 实际 Checks 与上传 artifacts 为准。本地没有 Docker，未声称已在本机完成镜像构建。
本轮还修复了 develop 的无日期打卡列表用 `LocalDate.MIN/MAX` 查询 MySQL 的问题：
未提供边界时不加对应条件，保留原有基础 smoke 验证，未放宽断言。
