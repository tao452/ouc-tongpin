## 复现方法

在 `services/algo/` 下运行：

```powershell
python -m ruff check app tests scripts ../../scripts/qa ../../scripts/w1 ../../scripts/release
python -m pytest -q
python scripts/evaluate_dataset.py ../../docs/qa/data/w2-moderation-regression.jsonl --min-benign 200 --min-blocked 100 --output ../../qa-private/w2-moderation-function.json
```

Java 测试在 `services/api-server/` 下运行 `mvn -B -q verify`。
容器测试由 `.github/workflows/deploy-test.yml` 在 GitHub Actions 的临时环境执行，结束后清理。
CI 运行记录见 [42578696529](https://github.com/tao452/ouc-tongpin/actions/runs/42578696529)，
样本说明见 [`data/README.md`](data/README.md)，后端调用方法见
[`MODERATION.md`](../../services/api-server/MODERATION.md)。
