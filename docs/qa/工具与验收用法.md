# M6 测试与验收工具

以下工具已实现；业务验收结果需用实际环境和经审核的数据另行记录。

## 正式词库接入

启动算法前设置 `MODERATION_DICTIONARY_PATH` 指向审核后的 UTF-8 JSON 文件。
未设置时仍使用 5 词示例库，不应据此宣布审核能力就绪。
设置后**完整替换**示例库；文件不存在、字段类型错误、未知等级、冲突别名会使启动失败。
格式与 `services/algo/app/data/words.json` 一致：word、level、aliases 数组、pinyin 布尔值。
规则文件受信任管理员维护，不接受用户请求指定文件路径；改词库后重启服务并复测。

```powershell
$env:MODERATION_DICTIONARY_PATH = '审核后词库的绝对路径'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

## 独立标注集评估

将数据放在仓库根 `qa-private/`（已忽略），不要提交真实个人信息。
每行一个 JSON 对象，格式为 `{"id":"唯一编号","text":"经审核的样本文本","expected_passed":true}`。
expected_passed 必须由标注人给出，不由脚本猜测。允许/拦截两类都必须有样本。
在 `services/algo/` 执行：

```powershell
python scripts/evaluate_dataset.py ../../qa-private/labeled.jsonl --dictionary ../../qa-private/words.json
```

报告包含混淆矩阵、召回率、误杀率、函数 P95 和数据文件哈希，不包含原文或样本 ID。
退出码 0 表示在**所给样本**上达到召回 ≥95%、误杀 <2%；1 表示未达到；2 表示输入无效或类别不全。
它不证明标注正确、样本独立，也不能用来替代真实并发/HTTP 性能或生产验收。
当前没有组长审核后的正式标注集，因此尚未给出业务效果达标结论。

## 离线 PII 扫描

在授权测试环境导出有限字段样本、测试日志到本地私有目录，然后在仓库根执行：

```powershell
python scripts/qa/pii_scan.py qa-private/export.txt qa-private/test.log
```

退出码 0 为未匹配规则，1 为存在疑似项，2 为输入不可读/格式错误。
只输出输入文件的顺序编号、行号和规则名，不输出匹配值；输入路径也不写入报告。
结果需人工复核：规则无法覆盖任意姓名、地址、图片或加密字段，“未命中”不能证明无隐私泄露。
本工具不连数据库。真实身份分表和数据最小化仍需表结构审查与访问权限测试。
