# M6 测试与验收工具

本页说明工具的使用方法。第二周的测试结果见 [完成情况](W2-内容安全交付与验证.md)。

## 正式词库接入

启动算法前设置 `MODERATION_DICTIONARY_PATH`，指向 M1 确认的 UTF-8 JSON 词表。
未设置时使用 5 词示例库；正式词表和等级等 M1 确认。
设置后**完整替换**示例库；文件不存在、字段类型错误、未知等级、冲突别名会使启动失败。
格式与 `services/algo/app/data/words.json` 一致：word、level、aliases 数组、pinyin 布尔值。
W2 新增可选 `allow_phrases` 数组，必须是包含本词条/别名的更长正常短语，
仅豁免同一个词条在该短语覆盖范围内的命中，不会全局放行整条内容。
词库路径由管理员通过环境变量配置；更新词库后重启服务并复测。

```powershell
$env:MODERATION_DICTIONARY_PATH = '词表文件的绝对路径'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

## 独立标注集评估

将数据放在仓库根 `qa-private/`（已忽略），不要提交真实个人信息。
每行一个 JSON 对象，格式为 `{"id":"唯一编号","text":"样本文本","expected_passed":true}`。
expected_passed 由标注人填写，样本需同时覆盖允许和拦截两类。
在 `services/algo/` 执行：

```powershell
python scripts/evaluate_dataset.py ../../qa-private/labeled.jsonl --dictionary ../../qa-private/words.json
```

报告包含混淆矩阵、召回率、误杀率、样本量、P95 和数据文件哈希，不包含原文或样本 ID。
支持 `--output` 保存报告；拒绝重复 ID 和相同正文。
`--min-benign` / `--min-blocked` 可限定两类最低样本量，不足时返回 2。
`--base-url http://127.0.0.1:8080` 切换为真实 HTTP 顺序评估，与 `--dictionary` 互斥；
HTTP 模式输出 `http_p95_ms`；远端词表版本由部署方记录。
退出码 0 表示这批样本的召回率 ≥95%、误杀率 <2%；1 表示未达到；2 表示输入无效或类别不全。
M6 准备测试文本和预期结果，需要时请 M1 确认标签；另选一批没有用于调词的样本可做补充检查。
个人任务书没有把独立标注文本列为 M1 第二周的必交材料。词表规则确认后复测，并发、HTTP 性能和业务环境分别测试。
W2 另有 300 条公开合成回归样本，并已接入 CI；详见 `data/README.md`。
开发回归达标与正式业务效果验收分别记录。

## 离线 PII 扫描

在授权测试环境导出有限字段样本、测试日志到本地私有目录，然后在仓库根执行：

```powershell
python scripts/qa/pii_scan.py qa-private/export.txt qa-private/test.log
```

退出码 0 为未匹配规则，1 为存在疑似项，2 为输入不可读/格式错误。
只输出输入文件的顺序编号、行号和规则名，不输出匹配值；输入路径也不写入报告。
扫描结果需人工复核；姓名、地址、图片及加密字段另行检查。
工具用于离线文本扫描；身份分表和数据最小化待表结构审查与访问权限测试。
