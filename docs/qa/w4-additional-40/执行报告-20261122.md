## 复现

在本分支干净checkout中安装Python3.11+、JDK17/Maven、Docker Compose，确保测试端口空闲：

```sh
python scripts/qa/w4_new40/run_owned.py --project ouc-w4-new40-local --output qa-private/w4-new40/results.json
python docs/qa/w4-additional-40/validate_design.py
```

入口创建随机凭据、从源码构建五服务、确认空库后执行HTTP和Java，最后核验项目标签并仅回收本项目资源。若`qa-private/w4-closeout/.env`已存在则拒绝覆盖，应使用新的干净checkout。Windows需已启动专用Docker socket，Linux默认系统Docker，也可用`W4_DOCKER_HOST`明确指定。

默认Java单元CI不启动专用环境，10条深度集成测试通过`W4_REAL_STACK=true`显式启用。CI跳过不算本报告的PASS；本报告结果来自独立环境实际执行。
