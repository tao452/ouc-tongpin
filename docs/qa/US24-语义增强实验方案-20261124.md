# US24 语义增强开发实验

v3的新外部广义召回仍不达标，继续做离线语义实验，不以等待团队回复作为暂停技术改进的条件。现有S1接口和默认5条库保持原有处理口径。

## 模型与运行方式

使用[Qwen官方Qwen3Guard-Gen-0.6B](https://huggingface.co/Qwen/Qwen3Guard-Gen-0.6B)，revision `fada3b2f655b89601929198343c94cd2f64d93cc`，Apache-2.0。上游safetensors应为1,503,300,328字节，SHA256 `4f3ce47ebd968cddb67de08d8764f8ede7c410a7d1fb9e08145a4c7a2f2e5c0f`。首轮下载截断已在推理前拦截，重新获取后须验证完整SHA256才可使用。

本机Ollama0.40的safetensors导入依赖不可用的MLX，q8_0/int8尝试都未进入推理。改用固定llama.cpp b6500提交`a7a98e0fffed794396b3fbad4dcdbbc184963645`将已验证作者权重转为F16 GGUF，再通过本机已有Ollama及任务专属模型名称运行。记录Ollama版本、转换后模型digest、源文件哈希、模板哈希和代码哈希。模型和外部原文留在本机，不上传到在线推理服务，不发布模型。若另用CPU动态INT8，应作为独立配置记录，不混为同一版本。

## 预先固定的开发对照

- 全部历史PCR500作为开发集，保留250阳性、250阴性和重复行。
- 旧v2与当前v3中所有`expected_word`为空的负例都作为正常语境对照，含举报、科普、英语、标识符、拼音、校园日常和心理求助。保留重复项及原标签；缓存相同文本的推理可复用，统计仍逐原ID保留。
- 分别统计原文、原文加完整词语默认读音拼音行、精确语境片段遮盖后加拼音三种输入。遮盖仅复用v3已有context_spans明确匹配的词条范围；同句其他攻击保留，不使用“举报/求助”全句白名单。使用作者的user-only chat_template，不改成要求模型输出目标标签的提示。
- 固定greedy、seed20261124、4096输入token、最多64输出token。输入超限显式报错，不截断或删行。
- 分别报告仅Unsafe、Unsafe或Controversial两种预设告警口径，并额外报告限制在Unethical Acts/Violent类目的冒犯告警。自伤类别独立记录，不按普通辱骂阻断。不能在外部集看过结果后挑更好的一组作正式指标，模型标签不自动映射为业务HIGH/MEDIUM/LOW。
- 解析失败保留原ID和失败原因，报告覆盖率，验收标记false；统计如给最坏情况矩阵，阳性未知计FN、阴性未知计FP并明确说明，不静默排除。

逐行保存预测、类别、耗时、ID和文本SHA256，公开证据不含原始正文。所有失败、困难正负例和首轮结果保留；Recall目标仍≥95%，FPR严格<2%，Precision同步报告。

## 新数据与验收

PCR、COLD test以及本次已评测ToxiCN均为历史开发资料，后续结果不称全新独立验收。开发方案固定后，另封存项目未用于调参的COLD dev作为外部对照，记录完整版本、SHA256、重复和重合；公开模型预训练数据未完全披露，因此另需M3封存新的校园人工样本作正式效果验收。

此实验不进入S1阻断，不更改已确认的等级处理口径，也不等于完成W9危机识别。实验不达标时继续保留真实结果，不把模型“安全”标签当作心理求助的完整判断。
