# US24 评论分类实验与外部验收方案

前两组离线模型对照未达标，继续验证专门的“评论是否包含冒犯”任务，使用本地Qwen3-4B-Instruct-2507 Q8_0。源模型为[Qwen官方Instruct](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)，本机权重来自[Ollama固定公开标签](https://ollama.com/library/qwen3:4b-instruct-2507-q8_0)，完整模型digest在首次预测前记录。

## 开发设计

提示词文件`data/comment-classifier.v1.prompt.json`包含任务定义、10个合成示例和固定输出schema。示例覆盖谐音、普通校园交流、医学与代码词、举报、举报后继续攻击、心理求助及求助后攻击。它们属于开发材料；与既有开发集的重复不作独立效果依据。

输出`offense_score`为0～100整数，仅为模型的冒犯判断分数，未经概率校准，不对应HIGH/MEDIUM/LOW；`crisis_hint`只作待人工关注的模型线索，不作完整危机理解或全句豁免。同句既有求助又有攻击时仍判断攻击。

全部历史PCR500及v2/v3全部正常负例257条保留，以原标签计算；重复正文可缓存推理，原ID及重复统计仍全部保留。PCR和正常语境组分别统计FPR，不能混池稀释某一组误报。仅在开发数据上比较原文加拼音、局部精确语境遮盖加拼音，以及字面规则与模型的OR组合。

固定本地推理、greedy、seed20261124、8192输入token、96输出token。输入超限、网络失败、版本改变或输出格式错误必须记录，不能算通过。错误行在最坏情况矩阵中，阳性记FN、阴性记FP；存在推理错误时指标门槛保持false。

预设阈值网格为1、5至95（步长5）、99、100。选择只使用开发数据：PCR和独立正常语境组均FPR<2%、推理错误0，再最大化PCR Recall；若没有Recall≥95%的配置，保留失败，继续开发，不能把低召回配置写成达标。

精确语境仍只遮盖`context_spans`命中的片段，同句其他攻击保留；不以“举报”“求助”等单词建立全局白名单。JSON序列化转义模型角色分隔符，保持原样本逻辑值，阻止样本中的角色标记改变对话边界。

## 外部验收

PCR、旧COLD test及本次ToxiCN已用于项目开发或评估，继续保留历史结果。开发方案选定后，冻结代码、提示词、词库、分词器文件、模型digest、依赖版本、语境开关、组合方式和唯一阈值，再首次获取COLD dev作为项目未参与调参的外部对照。

使用COLD仓库固定revision `a0c55a945497ab58e94aef491180e1cf88ffb864`的`COLDataset/dev.csv`；保留全量、原始二值label和topic分组，记录SHA256及原始字节数。先查重复及与历史资料重合，主结果不删除，另按预先规定的无重合分组报告。标签、困难样本和阈值不随预测结果修改。

外部模式只执行冻结的唯一阈值，不生成可挑选的阈值曲线；推理错误仍计入并阻止指标通过。若继续依据外部错误调整，该外部版本转为历史，新一版正式验收另封存数据。公开模型训练数据未完全披露，项目未参与调参不等于能证明模型从未见过公开语料；校园正式效果仍须M3另行封存新人工样本独立执行。

此脚本属于离线开发，S1处理口径、默认5条库、API路由和部署行为不变。逐词建议与新豁免继续PENDING，PR保持Draft，不提交业务批准或发布版本。

## 第二组模型对照

4B两组757条开发实验完成，均未达标，完整预测和失败结果保留。继续比较[Qwen3.5-9B官方模型](https://huggingface.co/Qwen/Qwen3.5-9B)，使用[Ollama公开固定标签](https://ollama.com/library/qwen3.5:9b-q4_K_M)的Q4_K_M版本。模型下载完成后核对完整digest并建立任务专用别名，不调用云端推理。

该组使用v2提示词，任务定义和合成示例保持相同，通过官方分词器模板明确关闭thinking；96输出token、8192输入token、greedy和seed保持固定。使用3.3候选库和局部精确语境遮盖；39个拼音词的数字声调只匹配词语上下文读音或显式登记的整词读法，不排列各字声调组合。规则、代码、分词器、提示词和模型digest均在首条预测前记录。

此组仍使用PCR500和257条正常语境资料进行开发，不能称为新独立验收。只有PCR Recall≥95%、PCR及正常语境各自FPR<2%、推理错误0的配置，才进入下一批外部样本冻结；未过线继续记录失败。
