# US24 阈值精度与固定三模型对照

本项继续使用原3258条开发样本。它补充检查阈值精度与模型错误的互补性，不产生新的独立效果结果；原固定0.001网格、标签、困难样本和各轮完整报告保留。

原网格在置信度接近1时可能跳过不同的决策集合，因此追加检查全部实际分数、各分数下一可表示浮点边界及原999点，范围固定[0,1]。每个配置仍只使用一个全局阈值，逐组要求FPR<2%、正样本Recall≥95%、错误0。阈值以完整精度保存，不能把显示时的三位小数当作同一配置。

三模型成员固定为RoCBert第2轮、当前3.9输入复核的ChineseBERT和域内Qwen第2轮，分别比较算术均值、几何均值、最小值、最大值。每条样本统一使用同一算法，未根据标签或类别选模型。成员来自已完成的开发实验，存在开发选择偏差；任一成员推理错误按不利方向计错。3258条ID、标签、类别、原文SHA和字面标记逐项一致后才组合。
