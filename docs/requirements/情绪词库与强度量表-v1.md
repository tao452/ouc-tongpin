# 情绪词库与强度量表 v1

版本：1.0.0。日期：2026-11-02。设计依据：仓库现有 OpenAPI 的六类情绪与 1–5 强度范围。
机器可读数据为 `packages/contract/emotions.v1.json`，前后端读取同一份编码与名称。

## 情绪词

| 编码 | 名称 | 说明 |
|---|---|---|
| HAPPY | 开心 | 愉快、满足或兴奋 |
| CALM | 平静 | 放松、安稳或心情平和 |
| ANXIOUS | 焦虑 | 担心、紧张或对事情感到不安 |
| LONELY | 孤独 | 缺少陪伴或希望有人交流 |
| IRRITABLE | 烦躁 | 不耐烦、心烦或容易受到打扰 |
| DOWN | 低落 | 难过、失落或提不起精神 |

## 强度

界面提问：“此刻这种感受有多强？”

| 值 | 名称 | 描述 |
|---|---|---|
| 1 | 很轻 | 只有一点，偶尔能察觉到 |
| 2 | 较轻 | 能感觉到，程度比较轻 |
| 3 | 中等 | 感受比较明显 |
| 4 | 较强 | 感受很明显，较难忽略 |
| 5 | 很强 | 感受非常强烈 |

六类情绪共用该量表。强度记录个人当下的主观感受，数值不作好坏排序。
保存字段为 emotion 和 intensity；中文名称和描述用于展示，升级文案时保留原编码。
本量表用于日常记录，没有临床诊断或危机等级含义。

## 接入与校验

- M5 的 `GET /api/emotions/words` 返回 words 与 intensityScale，对齐现有 OpenAPI。
- M3 使用同一 JSON 作为界面词表来源，提交时发送编码及整数强度。
- 服务端校验编码属于上述六项、强度为 1–5；边界和非法值纳入接口用例。
- 本次交付词库与量表设计数据，登录、持久化和词表业务接口由 M5 接入。
