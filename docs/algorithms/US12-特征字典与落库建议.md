# US12 特征字典与落库建议

版本 `features-v0.1-proposed`，初始权重 `equal-w0.1-proposed`。本文件供M1/M5审核，计算协议见[冻结方案](US12-W5W6-特征与评估方案.md)。

| 字段 | 类型/范围 | 说明 |
|---|---|---|
|emotion_similarity|float [0,1]|六维非负情绪向量的余弦相似度；零/缺失向量为0|
|emotion_complement|float [0,1]|有效向量时为1减相似度；数学差异，暂不参与评分|
|interest_jaccard|float [0,1]|NFKC、首尾空白、小写和去重后的集合交并比；保留C++等标点|
|time_jaccard|float [0,1]|带时区时间区间先各自合并，再按交并时长计算；相接不相交|
|distance_m|float≥0或null|Haversine球面距离，米；缺失为null|
|distance_decay|float [0,1]|exp(-distance_m/5000)；缺失为0|
|available|4个bool|emotion/interests/time/distance两侧输入是否有效；不是推荐质量标签|
|score|float [0,100]|100×四维加权和，6位小数；缺失不重新归一化|
|feature_version/weights_version|1～64字符|计算定义和权重版本|
|config_sha256|64位十六进制|加载配置原始字节的SHA256，与HTTP响应头一致|

输入按HAPPY/DOWN/CALM/ANXIOUS/LONELY/IRRITABLE顺序提供6维[0,1]数值；本服务没有实现从自然语言推断情绪。兴趣最多32项、每项32码点，时间最多16段，候选最多100个。时间须有时区、结束晚于开始，RFC3339子集小数秒最多6位、时区偏移[-18:00,+18:00]，转换UTC后年份为1～9999；拒绝溢出偏移和闰秒。纬度[-90,90]、经度[-180,180]，拒绝NaN/Infinity；两极和跨经线有边界测试。

## 存储草案

[schema-proposal.sql](../../services/algo/match/schema-proposal.sql)提供特征快照表，保存合成/内部请求键、候选键、两个版本、配置与输入数据哈希、数值特征、分数及降级标记。唯一键覆盖请求/候选/特征版本/权重版本；分数CHECK约束0～100。

此DDL在独立临时MySQL中实际创建并写入5000条HTTP评分特征；重复键和越界分数均被拒绝。它尚未加入`infra/db/init`或迁移，也没有接入真实用户数据。服务本身不保存评分请求。M5接入时需在私有数据层完成授权、账号映射、保留期限和批次幂等，不向公开reader角色授权原始画像或此表。

Java客户端当前返回排序分数、版本与降级原因；逐维解释保留在算法响应中。正式业务的特征快照写入、公开匹配路由、资料授权和页面展示由M5/M1对齐后接入。

## 初始权重

情绪相似、兴趣、时间、距离各0.25，距离尺度5000米。权重之和必须为1，配置启动时验证；修改配置须另存版本并重新评估。当前权重为初稿，M1尚未确认效果门槛和情绪互补的业务含义。
