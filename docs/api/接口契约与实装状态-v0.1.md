## 二、请求 / 响应与错误码速查

> 完整字段以 `openapi.yaml` 为准，本表只做速查。

| 接口 | 请求要点 | 成功响应 | 错误码 |
|---|---|---|---|
| `POST /api/auth/login` | `code`（必填） | 200：`token` / `userId` / `isNewUser` / `needStudentVerify` | 401 code 无效 |
| `POST /api/auth/student-verify` | `studentId`（必填）、`screenshotUrl` | 200：`status` ∈ PENDING / VERIFIED / REJECTED、`reason` | 409 学号已被绑定 |
| `GET /api/emotions/words` | — | 200：`words[]`（`code` / `label` / `colorToken`）、`intensityScale{min,max}` | — |
| `POST /api/emotions/checkins` | `emotion`（6 枚举）、`intensity`(1–5)、`note`(≤100)、`checkinDate` | 200：`Checkin`（同日重复返回已有记录） | 400 参数非法 |
| `GET /api/emotions/checkins` | `from` / `to`（date） | 200：`items[]` / `streakDays` / `total` | 400（如 11 月传 11/31 这类非法日期） |
| `POST /api/treehole/posts` | `content`(≤500)、`emotionTag`、`anonymous` | 201：`TreeholePost` | 400 空白 / 超长、422 命中 HIGH、503 审核不可用 |
| `GET /api/treehole/posts` | `emotionTag`、`cursor` | 200：`items[]` / `nextCursor` | — |
| `POST /api/match/needs` | `scene`、`time`、`location{address,lat,lng}`、`skillTags`(≤5)、`remark`(≤200) | 201 裸对象：`id`（字符串）/ `scene` / `status`（默认 OPEN） | 400 参数非法、422 送审命中 HIGH、503 审核不可用 |
| `POST /api/moderation/check` | `text`(1–2000，`additionalProperties:false`) | 200：`passed` / `normalized` / `hits[]{word,level}` | 422 参数无效（不回显输入）、413 超网关 16 KiB |
| `PUT /api/user/profile` | `nickname` / `avatarUrl` / `bio` / `interestTags` / `skillTags` | 200 更新成功 | — |

> **失败关闭**：`POST /api/treehole/posts` 与 `POST /api/match/needs` 在审核服务超时 / 非 2xx / 响应无效时统一 503，**业务不得写库**，不能「超时默认放行」。

## 四、已知差异 / 未完成（如实留痕）

1. **2 个 path 未实装**：`POST /api/auth/student-verify`、`PUT /api/user/profile` 实测 404；契约仍保留定义，供后续迭代实现，不写成「已完成」。
2. **JWT 未接**：契约 `login` 返回 `token` 并要求 `Authorization: Bearer`，实际所有请求仍是 demo `userId=1L`，无多用户隔离。
3. **管理端无契约 / 无实现**：`/api/admin/*` 未定义，`admin-web` 是写死 mock 的 UI 雏形。
4. **树洞详情与抱抱数**：契约 `TreeholePost` 有 `hugCount`（Redis SETNX + 24h）与 `expiresAt`，但无 `GET /api/treehole/posts/{id}` path，`hugCount` 未在表结构落地；24h 到期端到端未验收。
5. **广场列表无 GET 契约**：`buddy_demand` 只存发布内容，筛选 / 距离排序留给 V1.0 `#12`；前端广场仍是标注「示例需求 · 演示数据」的假卡片。
6. **词库与 PII 验收未完**：#25（正式词库 / 等级）、#26（真实业务 PII 验收）仍 OPEN；三级动作沿用开发基线，非正式业务口径。
7. **契约测试覆盖面有限**：`test_implementation_matches_repository_contract` 只逐字段比对 `/api/moderation/check` 的请求 / 响应，`test_emotion_lexicon.py` 只校验词表；**不等于 8 个 path 都有自动化契约测试**。
8. **口径不变**：V0.1 里程碑仍是 **9 关 / 2 开**（#4 / #11 由 M1 拍板关单、M4 独立复核未做）；归档 55 PASS / 25 BLOCKED 与最新 CI 63 PASS / 17 BLOCKED 两层口径不变，`production_acceptance=false`。
