# W4 设计走查材料

## 1. 文件夹说明

本文件夹用于存放 OUC同频小程序 W4 阶段的设计走查材料，包括页面检查记录、界面截图、问题标注及相关视觉验证材料。

## 2. 走查范围

本阶段主要涉及以下模块：

- 首页模块
- 打卡模块
- 树洞模块
- 校园广场模块
- 我的模块

## 3. 材料组织

后续可按模块或材料类型整理文件，例如：

- 页面截图：记录走查时的实际界面表现
- 问题记录：记录发现的问题、问题等级及处理状态
- 视觉检查：记录页面布局、颜色、字体、间距等视觉表现
